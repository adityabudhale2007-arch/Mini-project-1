# Smart Classroom & Timetable Scheduler

Responsive HTML/CSS frontend with a small JavaScript scheduling layer.

## Run
1. Extract the ZIP.
2. Open `index.html`.
3. Login using any dummy credentials.
4. Open **Schedule Class**.
5. Add a class and open **Timetable** to see it immediately.

## Scheduling functionality
- Adds classes dynamically.
- Saves schedules in browser `localStorage`.
- Detects classroom conflicts.
- Detects teacher conflicts.
- Detects class/semester conflicts.
- Validates start/end times.
- Allows deleting scheduled classes.
- Includes a button to restore the original demo timetable.

No backend is required for this demo. Data is stored locally in the browser.
